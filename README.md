# Технологія продажу — сайт оголошень

Це простий статичний сайт для показу твоїх оголошень. Він працює з `products.json` (масив обʼєктів товарів). Кожен товар може мати до 10 зображень (jpg/png/gif).

Головні файли:
- `index.html` — сторінка сайту.
- `styles.css` — стилі.
- `script.js` — логіка відображення, адмін-інструмент (клієнт).
- `products.json` — дані товарів.
- `images/` — туди завантажуй фото товарів.

1. Зава��таж файли у корінь репозиторію (index.html, styles.css, script.js, products.json, README.md).
2. Створи/завантаж папку images/ з фото.
3. Settings → Pages → Source: main / (root) → Save.
4. Сайт буде доступний за адресою, вказаною у Pages (https://BustrunFV.github.io/bustrun-products).
