Інструкція для адмініна
  1. Після натискання "Згенерувати" з'явиться файл new-product.json — скачай його.
  2. Завантаж фото в папку images/ репозиторію (через Upload files).
  3. Відкрий products.json → Edit і додай обʼєкт з new-product.json у масив → Commit changes.
